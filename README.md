```sh
brew install --cask timenty/tap/lidawake
```

| Cask | Description |
|---|---|
| [`lidawake`](Casks/lidawake.rb) | [LidAwake](https://github.com/Timenty/lid-awake) — menu bar toggle to keep a Mac awake with the lid closed |
